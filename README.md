# Kearney Property Tax Calculator

## Free Hosting Setup (GitHub Pages)

### Step 1: Create a GitHub account (if you don't have one)
1. Go to https://github.com and click "Sign up"
2. Follow the steps (free account is all you need)

### Step 2: Create a new repository
1. Click the "+" icon in the top right, then "New repository"
2. Name it: `kearney-tax-calc`
3. Set it to **Public**
4. Check "Add a README file"
5. Click "Create repository"

### Step 3: Upload the files
1. In your new repository, click "Add file" > "Upload files"
2. Drag all these files into the upload area:
   - `index.html`
   - `manifest.json`
   - `sw.js`
   - `icon-192.png`
   - `icon-512.png`
3. Click "Commit changes"

### Step 4: Enable GitHub Pages
1. Go to your repository's "Settings" tab
2. Click "Pages" in the left sidebar
3. Under "Source", select "Deploy from a branch"
4. Under "Branch", select "main" and "/ (root)"
5. Click "Save"
6. Wait 1-2 minutes, then your calculator will be live at:
   **https://YOURUSERNAME.github.io/kearney-tax-calc/**

### Using on iPhone
1. Open the URL in **Safari** (must be Safari for Add to Home Screen)
2. Tap the Share button (square with arrow)
3. Tap "Add to Home Screen"
4. It will appear as an app icon and work offline!

### Sharing
Just send anyone the URL - it works on any phone, tablet, or computer.
